СИСТЕМА УПРАВЛЕНИЯ ЗАЯВКАМИ «ХОП» (ХОЗЯЙСТВЕННО-ОПЕРАТИВНАЯ ПОДДЕРЖКА)
ТЕХНИЧЕСКОЕ ЗАДАНИЕ / ПРОМПТ ДЛЯ СОЗДАНИЯ АНАЛОГИЧНОЙ СИСТЕМЫ

1. ОБЩАЯ КОНЦЕПЦИЯ
Создать высокотехнологичную веб-платформу для автоматизации жизненного цикла хозяйственных заявок (ремонт, IT-поддержка, клининг и др.). Система должна быть легкой, быстрой (SPA), адаптивной и поддерживать работу с огромными массивами данных через два режима хранения (JSON/MySQL).

2. ТЕХНИЧЕСКИЙ СТЕК
- Backend: PHP 8.x (Rest API без внешних фреймворков для максимальной переносимости).
- Frontend: Vanilla JavaScript, HTML5, CSS3 (Bootstrap 5, Bootstrap Icons).
- Хранение: Гибридная модель Storage (Atomic JSON с блокировками flock для малых инсталляций и PDO MySQL для крупных).
- Безопасность: JWT (JSON Web Tokens) с автоматической ротацией секретного ключа, хеширование паролей Bcrypt.

3. ОСНОВНЫЕ МОДУЛИ И ФУНКЦИОНАЛ

А. ГИБКАЯ РОЛЕВАЯ МОДЕЛЬ (RBAC+)
- Роли: Администратор, Руководитель, Исполнитель, Пользователь.
- Гранулярные разрешения: Более 30 флагов доступа (редактирование, удаление, смена статуса, просмотр истории, управление пользователями и т.д.).
- Кастомизация интерфейса: Возможность индивидуально для каждого пользователя отключать вкладки меню (Задачи, Чат, Отдел, Отчеты, Админка).

Б. ЖИЗНЕННЫЙ ЦИКЛ ЗАЯВКИ
- Статусы: Новая -> Назначена -> В работе -> Выполнена -> Закрыта (с оценкой) / Отклонена.
- Автоматизация: Расчет SLA (дедлайна) на основе типа работ. История каждого изменения фиксируется в отдельной таблице.

В. ИНТЕРФЕЙС И UX
- Desktop: Профессиональный Dashboard с боковой панелью, табличными представлениями и Kanban-доской.
- Mobile First: Выделенный интерфейс (/mobile/) с нативным поведением (Bottom Nav, Fullscreen Modals, Glassmorphism).
- PWA: Поддержка Manifest и Service Workers для установки на смартфоны.
- Kanban 2.0: Драг-энд-дроп (SortableJS), цветовая индикация приоритетов, карточки с аватарами исполнителей. На больших экранах — 4 колонки в ряд.

Г. ФИЛЬТРАЦИЯ И ПОИСК
- Расширенные фильтры: Мгновенная фильтрация (auto-apply) по статусу, приоритету, типу работ, локации и текстовому поиску во всех разделах.

Д. КОММУНИКАЦИИ
- Общий чат для сотрудников.
- Контекстные комментарии внутри каждой заявки.
- Прикрепление фото и документов (валидация типов и размеров).

Е. АДМИНИСТРИРОВАНИЕ
- Управление структурой: Отделы, Типы работ (связка с отделами).
- Инструменты: Создание/восстановление бекапов (ZIP), логи входов, просмотр файлов сервера.
- Demo Seeding: Генератор тестовых данных (500+ заявок, история, чат) для быстрой демонстрации.

4. АРХИТЕКТУРНЫЕ ОСОБЕННОСТИ
- Шаблон «Стратегия» для Storage: Переключение между JSON и MySQL одной настройкой в конфиге.
- Централизованный Notifier: Логирование системных событий и уведомлений.
- Темизация: Поддержка визуальных тем (Modern, Midnight Pro, Emerald Glass) через CSS переменные.

5. ТРЕБОВАНИЯ К ДИЗАЙНУ
Использовать премиальную эстетику: скругленные углы (1rem+), тени (shadow-sm/md), полупрозрачные фоны (backdrop-filter: blur), градиенты для кнопок и статусных меток. Интерфейс должен выглядеть как современное SaaS-приложение.

ПОЛНОЕ ТЕХНИЧЕСКОЕ ОПИСАНИЕ СИСТЕМЫ CRM «ХОП» (V1.0)
Мастер-промпт для разработки и архитектурного проектирования аналогичных систем

1. МИССИЯ И НАЗНАЧЕНИЕ
CRM «ХОП» (Хозяйственно-Оперативная Поддержка) — это промышленное веб-приложение для автоматизации внутренних служб эксплуатации предприятий. Система обеспечивает полный цикл обработки заявок: от момента обнаружения неисправности сотрудником до подтверждения качества выполненных работ и сбора аналитики.

2. ТЕХНОЛОГИЧЕСКИЙ СТЕК (EXTREME PORTABILITY)
Система спроектирована по принципу «максимальная функциональность при минимальных зависимостях»:
- Backend: PHP 8.x (Native). Без использования тяжелых фреймворков (Laravel/Symfony), что позволяет разворачивать систему на любом дешевом хостинге.
- Frontend: Vanilla JavaScript (ES6+). Архитектура SPA (Single Page Application). Модульная структура без Node.js сборки.
- UI/UX: Bootstrap 5.3 + Custom CSS3 (Glassmorphism, CSS Variables).
- Интеграции: Chart.js для визуализации, SortableJS для Kanban-механик.

3. ГИБКАЯ СИСТЕМА ХРАНЕНИЯ (STRATEGY PATTERN)
Уникальная особенность — класс `Storage.php`, который прозрачно для остального кода переключает движок базы данных:
- JSON Mode: Идеально для малых групп (до 20-30 чел). Каждая «таблица» — это `.json` файл. Реализована защита от повреждения данных через `flock` (эксклюзивные блокировки при записи).
- MySQL Mode: Для средних и крупных компаний. Автоматическая миграция структуры таблиц при переключении. Использование PDO и Prepared Statements.

4. БЕЗОПАСНОСТЬ И RBAC (ROLE-BASED ACCESS CONTROL)
- Аутентификация: Stateless JWT (JSON Web Tokens). Токен хранится в LocalStorage, передается в Header `Authorization: Bearer...`.
- Секретный ключ: Система проверяет наличие `jwt_secret` в настройках. Если его нет — генерирует уникальный 32-байтовый ключ и сохраняет его навсегда, обеспечивая стабильность сессий.
- Права доступа: Реализовано более 30 атомарных разрешений (permissions). Каждая роль (Admin, Manager, Executor, User) имеет предустановленный набор прав, который можно переопределить индивидуально для пользователя.
- Изоляция данных: Реализована защита на уровне API (IDOR Protection). Пользователь видит только свои заявки, Начальник — заявки своего отдела, Админ — всё.

5. ЖИЗНЕННЫЙ ЦИКЛ ЗАЯВКИ (WORKFLOW)
Процесс автоматизирован через 9 состояний:
- New: Авто-создание, расчет SLA (дедлайна).
- Assigned: Руководитель назначил Исполнителя.
- In Progress: Исполнитель принял в работу.
- Waiting Parts / Postponed / Need Info: Промежуточные состояния для корректного учета времени.
- Completed: Исполнитель завершил работу.
- Closed: Заявитель подтвердил выполнение и поставил оценку (1-5 звезд).
- Rejected: Заявка отклонена или отправлена на доработку.
История: Каждое действие записывается в `status_history` (кто, когда, старый/новый статус, комментарий).

6. ФУНКЦИОНАЛЬНЫЕ МОДУЛИ
- Kanban 2.0: Динамическая доска с Drag-and-Drop. На широких мониторах (>1400px) автоматически выстраивается по 4 колонки в ряд для максимального охвата. Цветовая индикация приоритетов (High - красный, Normal - синий, Low - зеленый).
- Конструктор Форм: Админ может добавлять текстовые поля, списки и чекбоксы, которые динамически рендерятся в форме подачи заявки.
- Общий Чат: Real-time коммуникация между всеми сотрудниками.
- Система Уведомлений: Запись событий в `notifications.log` и визуальные алерты.
- Аналитика: Интерактивные графики нагрузки по отделам и среднего времени закрытия заявок.

7. MOBILE-FIRST И PWA
Система имеет выделенную мобильную версию (`/mobile/`):
- Native Feel: Нижняя панель навигации (Bottom Nav), полноэкранные модалки, отсутствие браузерных рамок.
- PWA: Настроенный Manifest и Service Worker позволяют устанавливать CRM как приложение на главный экран.
- Оптимизация: Сенсорное управление, облегченные списки карточек.

8. АДМИНИСТРИРОВАНИЕ И ОБСЛУЖИВАНИЕ
- Бекапы: Создание ZIP-архива всей системы (данные + конфиги) одной кнопкой.
- Логирование: Детальный аудит входов (IP, User Agent).
- Seed Demo: Генератор 500+ заявок за 1 клик для тестирования производительности.
- Файловый менеджер: Встроенный инструмент для управления медиа-файлами на сервере.

9. UX ПРИНЦИП: УМНАЯ АВТО-ФИЛЬТРАЦИЯ
В системе реализован принцип «Живых фильтров». Любое изменение в полях (ввод текста, выбор из списка) мгновенно инициирует запрос к API и перерисовку интерфейса без перезагрузки страницы, обеспечивая бесшовный пользовательский опыт.

10. РЕКОМЕНДАЦИИ ПО РАЗВЕРТЫВАНИЮ
Для работы достаточно Apache/Nginx + PHP 8.1+. Система полностью автономна и не требует доступа к интернету после загрузки фронтенд-библиотек (CDN можно заменить на локальные копии).

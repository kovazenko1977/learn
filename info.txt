# Документация wesbooking Pro (HOP Standalone)

## 1. Общее описание
**wesbooking Pro** — это полнофункциональная система управления бронированием (Property Management System), разработанная специально для санаториев, домов отдыха и банных комплексов. Система объединяет управление номерным фондом (посуточно) и услугами/ресурсами (почасово).

## 2. Архитектура системы
Приложение построено на базе **PHP 8.x** с использованием архитектурного паттерна, близкого к MVC, но адаптированного для работы без внешних зависимостей.

### Хранение данных (JsonStore)
Вместо SQL-баз данных используется проприетарное решение `Sanatorium\Core\Database\JsonStore`.
- **Формат:** Данные хранятся в `.json` файлах в папке `/data`.
- **Безопасность:** Доступ к папке `/data` закрыт через `.htaccess` (Deny from all).
- **Конкурентность:** Используется механизм `flock(LOCK_EX)` для предотвращения повреждения данных при одновременной записи несколькими пользователями. Каждая транзакция атомарна.

### Ядро (Core)
- **Autoloader:** Реализован стандарт PSR-4 для автоматической загрузки классов из пространства имен `Sanatorium\Core`.
- **BookingManager:** Центральный мозг системы, отвечающий за расчет цен, проверку доступности и управление жизненным циклом брони.
- **RoomManager:** Управление объектами (номерами, саунами) и их характеристиками.

## 3. Бизнес-логика и Механизмы

### Управление номерным фондом (Daily)
Система поддерживает сложные правила размещения:
- **Типы мест:** Разделение на основные и дополнительные места в рамках одного номера.
- **Подселение по полу:** При создании бронирования в многоместный номер система автоматически проверяет пол уже проживающих гостей. Запрещено селить мужчин к женщинам и наоборот (если это не предусмотрено правилами конкретного заезда).
- **Мягкие коллизии:** Система позволяет видеть частичную занятость номера (например, 1 место из 3).

### Почасовое бронирование (Hourly)
Для саун, процедур и услуг реализована почасовая сетка:
- **Буферное время:** Настраиваемое время на уборку/подготовку между сеансами (buffer_time).
- **Визуальный график:** Специальный интерфейс `hourly_grid.php` для управления короткими сессиями.

### Ценообразование
Алгоритм расчета стоимости учитывает:
1. Базовую стоимость номера/услуги.
2. Коэффициент за тип места (основное/доп).
3. Выбранные пакеты питания или лечения.
4. Дополнительные процедуры и разовые услуги.

## 4. Интерфейс и UX
- **Стиль:** Современный дизайн в стиле "Mica/Glassmorphism" с использованием CSS-переменных и плавных переходов.
- **Шахматка (Chessboard):** Интерактивный календарь, отображающий загрузку фонда, статусы оплат и пол проживающих (иконками).
- **Мобильная версия:** Адаптивный интерфейс в папке `/mobile` и поддержка PWA (Progressive Web App) для установки на смартфоны персонала.

## 5. Интеграция и расширение
- **Form Constructor:** Встроенный инструмент для генерации iFrame-форм, которые можно вставить на любой внешний сайт для онлайн-бронирования.
- **REST API:** Набор эндпоинтов в папке `/api` для интеграции с внешними сервисами или разработки кастомных мобильных приложений.

## 6. Безопасность и администрирование
- **RBAC:** Ролевая модель доступа. Каждому пользователю можно гибко настроить доступ к разделам (Аналитика, Настройки, Календарь и т.д.).
- **Audit Log:** Механизм переселения гостей (Relocation) автоматически логирует причины и время перемещения в заметки бронирования.
- **Health Check:** Раздел "Состояние системы" проверяет права доступа на папки, версию PHP и целостность базы данных.

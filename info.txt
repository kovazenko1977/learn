CRM ХОП (Хозяйственно-Оперативная Поддержка)
Версия: 1.0
Разработчик: Коваженко С.Б. (wes.by)

ОБЩЕЕ ОПИСАНИЕ
---------------------------------
CRM ХОП — это специализированная система управления заявками, предназначенная для автоматизации деятельности служб хозяйственно-оперативной поддержки в организациях любого масштаба. Она заменяет бумажные журналы и разрозненные чаты единой цифровой средой.

НАЗНАЧЕНИЕ СИСТЕМЫ
---------------------------------
1. Сбор заявок от сотрудников на ремонт, обслуживание, клининг и ИТ-поддержку.
2. Автоматизация распределения задач между исполнителями.
3. Контроль сроков выполнения (SLA) и качества работ через систему оценок.
4. Сбор аналитики для руководства о нагрузке на персонал и типичных проблемах.

ПРИНЦИПЫ РАБОТЫ
---------------------------------
- Role-Based Access Control (RBAC): Пользователи видят только те данные, которые необходимы им для работы согласно их роли (Заявитель, Исполнитель, Руководитель, Админ).
- Mobile-First: Система автоматически определяет устройство и предлагает оптимизированный интерфейс для смартфонов, что критично для исполнителей, работающих "на объектах".
- Двойная стратегия хранения: Возможность работы как на простых JSON-файлах (без базы данных), так и на промышленной СУБД MySQL.
- Интерактивность: Встроенные чаты в каждой заявке и система уведомлений (звук + браузерные push) минимизируют время реакции на инцидент.

ОСНОВНЫЕ ФУНКЦИИ
---------------------------------
- Создание заявок с прикреплением фотографий и выбором приоритета.
- Канбан-доска и табличное представление для управления очередью задач.
- Система подтверждения: заявка не считается закрытой, пока заявитель не подтвердит выполнение.
- Глобальный чат для оперативной связи всего персонала.
- Инструменты администратора: управление правами, бэкапы, экспорт в Excel, аудит входов.

ТЕХНИЧЕСКИЙ СТЕК
---------------------------------
- Backend: PHP 8.x
- Frontend: Vanilla JavaScript, Bootstrap 5, PWA
- Auth: JWT (JSON Web Tokens)
- Storage: JSON / MySQL 8.0+

РАЗВЕРТЫВАНИЕ И ПОДДЕРЖКА
---------------------------------
Система является легковесной и не требует сложных сборок. Для работы достаточно стандартного веб-сервера (Apache/Nginx) с поддержкой PHP. Вся конфигурация осуществляется через панель администратора.

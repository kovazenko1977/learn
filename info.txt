# HOP (Hospitality Online Platform) - Standalone Version

## Архитектура
Система построена на PHP 8.x без внешних зависимостей (кроме встроенных модулей JSON).
Все данные хранятся в папке `/data` в формате JSON для максимальной переносимости.

## Основные компоненты
- `admin/` - Панель управления (Рабочий стол, Справочники, Календарь, Конструктор)
- `mobile/` - Оптимизированный интерфейс для персонала
- `core/` - Логика приложения (Автозагрузчик, Работа с БД, Менеджеры сущностей)
- `api/` - REST API для фронтенда и сторонних интеграций

## Как развернуть
1. Загрузите файлы на сервер с поддержкой PHP 8.0+.
2. Убедитесь, что папка `data/` доступна для записи.
3. Откройте `index.php` для настройки.

## Управление
- **Объекты:** Создавайте типы (Классы) объектов, указывая тип бронирования: Посуточно (Номера) или Почасово (Сауны, Услуги).
- **Интеграция:** Используйте раздел "Конструктор" в админке, чтобы получить код для вставки формы на ваш сайт.
- **Безопасность:** В настройках можно включить авторизацию. По умолчанию вход `admin` / `admin123`.

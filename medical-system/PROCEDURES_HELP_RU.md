# Руководство пользователя: Медицинская Система

Данная программа предназначена для автоматизации записи и учета медицинских процедур.

## Роли и доступ
В системе предусмотрено 4 основные роли, каждая из которых имеет свой 6-значный код доступа:

1.  **Администратор** (Код: `123456`) — Полный доступ, справочники, аналитика.
2.  **Врач** (Код: `101010`) — Назначение процедур, выбор времени.
3.  **Кассир** (Код: `202020`) — Прием оплаты.
4.  **Медсестра** (Код: `303030`) — Отметка о выполнении процедуры.

## Инструкция по работе

### 1. Справочник процедур (Админ)
Перейдите в раздел **Справочник**. Здесь можно добавить наименование процедуры, её цену, длительность в минутах и время перерыва между пациентами.
*Если цена установлена 0, процедура будет считаться бесплатной.*

### 2. Назначение процедур (Врач)
Врач находит пациента по ФИО или телефону и выбирает одну или несколько процедур.
При выборе даты и процедуры система автоматически рассчитывает свободные временные слоты, учитывая длительность процедуры и перерыв.

### 3. Оплата (Кассир)
Кассир ищет пациента. Список процедур имеет цветовую индикацию:
- **Серый**: Бесплатная процедура.
- **Красный**: Требуется оплата.
- **Зеленый**: Оплачено.
Кассир отмечает оплаченные процедуры кнопкой "Оплатить".

### 4. Прием (Медсестра)
Медсестра видит список пациентов на сегодня. Процедуры, требующие оплаты, но не оплаченные, заблокированы для выполнения. После проведения процедуры медсестра нажимает "Принять", и статус меняется на "Выполнено".

### 5. Аналитика (Админ)
Раздел позволяет отслеживать количество назначений, процент выполнения и общую выручку за выбранный период времени.

## Техническая информация
Приложение расположено в директории `medical-system/admin/`.
Все данные хранятся в формате JSON в папке `data/`.
Доступ к данным защищен файлом `.htaccess`.

Обзор системы

Sanatorium 2.0 — это высокопроизводительная ERP/PMS платформа для автоматизации процессов в санаториях. Основные преимущества: отсутствие необходимости в тяжелой БД (JSON/SQLite), модульность, высокая скорость работы и адаптивность.

Модули

  • Accommodation (Размещение): Конструктор корпусов, управление статусами номеров.
  • Booking (Бронирование): Визуальная шахматка, управление очередями.
  • Guests (Гости): CRM для пациентов, история лечения.
  • Finance (Финансы): Биллинг, пакеты услуг, расчет себестоимости.
  • Entity Builder: Создание своих модулей без кода.

Техническая информация

Минимальные требования: PHP 8.3+. Для работы системы достаточно обычного виртуального хостинга. Рекомендуется использовать HTTPS для защиты персональных данных гостей.

СИСТЕМА УПРАВЛЕНИЯ ЗАЯВКАМИ: SERVICE CRM PRO
========================================================================

Service CRM PRO — это профессиональное решение для автоматизации процессов
технического обслуживания и ремонта в организациях любого масштаба.
Система объединяет в себе эстетичный современный интерфейс и мощный
функционал для контроля жизненного цикла заявок.

------------------------------------------------------------------------
1. ОСНОВНЫЕ ВОЗМОЖНОСТИ
------------------------------------------------------------------------

● Интерактивная Канбан-доска:
  - Визуальное управление статусами через Drag-and-drop.
  - Мгновенная фильтрация по приоритетам и полнотекстовый поиск.
  - Массовое назначение исполнителей в один клик.

● Продвинутая Аналитика (Dashboard):
  - Контроль выполнения SLA (Service Level Agreement) в реальном времени.
  - Расчет среднего времени выполнения заявок.
  - Визуализация загрузки каждого сотрудника (процентное соотношение задач).
  - Группировка данных по статусам: Новые, В работе, Выполнены.

● Конструктор Форм:
  - Администратор может создавать произвольные поля для заявок (текст,
    числа, даты, флажки) без изменения кода.
  - Динамическая отрисовка полей в интерфейсе создания заявки.

● Система Комментариев и Истории:
  - Полноценные диалоги внутри каждой задачи.
  - Детальный лог активности: кто, когда и на какой статус перевел задачу.

● Мультиплатформенность:
  - Полная адаптация под мобильные устройства.
  - Поддержка темного и светлого режимов (Dark Mode) для комфортной работы.

------------------------------------------------------------------------
2. РОЛИ И ПРАВА ДОСТУПА (RBAC)
------------------------------------------------------------------------

● Администратор:
  - Полный доступ к настройкам системы, пользователям и конструктору форм.
  - Переключение режимов хранения данных (JSON/MySQL).

● Начальник отдела:
  - Просмотр всех заявок, назначение исполнителей, контроль SLA.
  - Доступ к расширенной аналитике.

● Исполнитель (Техник):
  - Работа только с назначенными ему задачами.
  - Смена статусов (В работе -> Выполнено), добавление комментариев.

● Ответственный сотрудник:
  - Создание новых заявок через упрощенный интерфейс.
  - Отслеживание прогресса по своим запросам.

------------------------------------------------------------------------
3. ТЕХНИЧЕСКИЙ СТЕК И АРХИТЕКТУРА
------------------------------------------------------------------------

● Frontend: Vue.js 3, Tailwind CSS (тема 'Strict' Slate-900), Inter Font.
● Backend: PHP 8.x (RESTful API), JWT (JSON Web Tokens) для авторизации.
● Хранилище: Гибридное (Hybrid Storage).
  - По умолчанию: JSON файлы (для быстрого развертывания).
  - Опционально: MySQL (с автоматической генерацией схемы таблиц).
● Безопасность:
  - Хеширование паролей (BCRYPT).
  - Валидация типов файлов и MIME-проверка вложений.
  - Маскировка чувствительных данных (токены, пароли) в API.

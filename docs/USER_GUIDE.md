# Руководство пользователя LabelPro

## 1. Введение
LabelPro — это профессиональное решение для создания и печати промышленных этикеток.

## 2. Начало работы
- **Каталог товаров**: Добавьте ваши продукты в базу данных, указав название, ГОСТ, артикул и другие характеристики.
- **Шаблоны**: Создайте новый шаблон этикетки или выберите существующий из библиотеки.

## 3. Визуальный редактор
- **Drag & Drop**: Просто перетаскивайте элементы (текст, штрихкод, знаки ГОСТ) на холст.
- **Свойства**: Выделите элемент, чтобы изменить его параметры в правой панели.
- **Переменные**: Используйте `{PRODUCT}`, `{DATE}`, `{BATCH}` для автоматической подстановки данных при печати.

## 4. Стандарты и Штрихкоды
- **ГОСТ 14192-96**: Библиотека транспортных знаков доступна в левой панели.
- **EAN-13, Code128, DataMatrix, QR**: Генерация происходит автоматически согласно введенным данным.

## 5. Печать
- **Предпросмотр**: Нажмите кнопку "Печать", чтобы увидеть финальный PDF.
- **Термопринтеры**: Приложение оптимизировано для работы с Zebra, TSC и другими принтерами этикеток.

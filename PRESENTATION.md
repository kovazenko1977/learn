# CRM HOP: Система управления заявками v1.0
## Современное решение для Хозяйственно-Оперативной Поддержки

---

## 1. Концепция и Назначение
**CRM HOP** — это высокотехнологичная веб-платформа, созданная для полной автоматизации жизненного цикла хозяйственных заявок внутри организации.

*   **Централизация:** Единая точка входа для всех запросов на обслуживание.
*   **Прозрачность:** Реальный статус каждой заявки доступен всем участникам.
*   **Оперативность:** Автоматическая маршрутизация в профильные отделы.
*   **Analytics:** Глубокая отчетность и визуализация через Kanban-доски для принятия управленческих решений.

---

## 2. Mobile-First & Native Experience
Система спроектирована с приоритетом на мобильных пользователей (исполнителей и сотрудников "в полях").

*   **Интерфейс "Native App":** Нижняя панель навигации (Bottom Nav Bar) и плавающая кнопка действия (FAB).
*   **Эргономика:** Полноэкранные мобильные модальные окна и контекстные меню в стиле "Bottom Sheet".
*   **PWA (Progressive Web App):** Возможность установки на главный экран смартфона, работа без лишних элементов браузера.
*   **Glassmorphism Design:** Современный визуальный стиль с эффектами матового стекла и профессиональными градиентами.

---

## 3. Ролевая модель (RBAC)
Гибкая система прав доступа обеспечивает безопасность и фокус на задачах.

*   👤 **Пользователь (User):** Подача заявок, чат с исполнителем, оценка качества.
*   🛠️ **Исполнитель (Executor):** Работа с очередью отдела, смена статусов, обратная связь.
*   📈 **Руководитель (Manager):** Назначение ответственных, контроль SLA, аналитика отдела.
*   ⚙️ **Администратор (Admin):** Управление пользователями, настройка справочников и хранилища (JSON/MySQL).

---

## 4. Жизненный цикл заявки
Четкая логика переходов между статусами исключает потерю задач.

1.  🆕 **Новая:** Создана сотрудником, ожидает назначения.
2.  📅 **Назначена:** Руководитель выбрал исполнителя.
3.  ⚡ **В работе:** Исполнитель приступил к выполнению.
4.  ✅ **Выполнена:** Работа завершена, ожидает проверки.
5.  🔒 **Закрыта:** Пользователь подтвердил качество и поставил оценку.
6.  🔄 **На доработке:** Если качество не устроило, заявка возвращается исполнителю.

---

## 5. Инструменты Администратора
Мощный функционал для управления системой.

*   **User Management CRUD:** Полный контроль над учетными записями и гранулярными разрешениями через систему шаблонов.
*   **Demo Seeding:** Мгновенное наполнение системы тестовыми данными (500+ заявок) для демонстрации и тестирования.
*   **Storage Strategy:** Легкое переключение между файловым хранилищем (JSON) и промышленной БД (MySQL).
*   **Security:** Журналирование входов, управление авторизацией и защита данных.
*   **Backups:** Создание и восстановление резервных копий одним кликом.

---

## 6. Визуальное управление и Аналитика
Эффективные инструменты для мониторинга нагрузки.

*   **Premium Kanban:** Профессиональные доски задач с цветовой кодировкой приоритетов, аватарами исполнителей и drag-and-drop управлением.
*   **Executor Drill-down:** Детальный аудит активности каждого сотрудника с поминутной историей действий.
*   **SLA Tracking:** Автоматический расчет времени выполнения и контроль просроченных заявок.

---

## 7. Коммуникации и Уведомления
Система держит участников в курсе событий в реальном времени.

*   💬 **Встроенный чат:** Обсуждение деталей прямо внутри карточки заявки.
*   🔔 **Умные уведомления:** Звуковые сигналы и браузерные Push-уведомления о новых задачах.
*   📢 **Объявления:** Возможность для админа транслировать важную информацию всем пользователям через баннер.

---

## 8. Технический Стек
Надежность и масштабируемость.

*   **Backend:** PHP 8.x — высокая производительность и доступность.
*   **Frontend:** Vanilla JS / Bootstrap 5 / PWA — быстрый отклик без тяжелых фреймворков.
*   **Storage:** JSON (для быстрого старта) / MySQL (для высокой нагрузки).
*   **Security:** JWT (JSON Web Tokens), Bcrypt hashing, HMAC-SHA256 signatures.

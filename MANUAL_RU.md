# Инструкция пользователя - CRM для обслуживания

## Вход в систему
Используйте ваш логин и пароль. По умолчанию: `admin` / `admin`.

## Роли пользователей
- **Администратор:** Управление пользователями, системные настройки, SLA.
- **Начальник отдела:** Назначение исполнителей (Drag-and-Drop), контроль всех заявок.
- **Ответственный:** Создание заявок от подразделений.
- **Исполнитель:** Работа по назначенным задачам, смена статуса на "Выполнено".

## Работа с заявками
1. **Создание:** Нажмите кнопку "Создать заявку", заполните тему, описание, выберите категорию и приоритет.
2. **Назначение:** В табе "Заявки" перетащите заявку из списка на имя исполнителя в левой колонке (для Администратора/Начальника).
3. **Обновление:** Кликните на заявку для просмотра деталей, добавления комментариев или смены статуса.
4. **SLA:** Система автоматически считает крайний срок. Если срок истек, метка станет красной и начнет пульсировать.

## Настройки
В разделе "Настройки" можно изменить:
- Список категорий и приоритетов.
- Множители SLA для каждого приоритета.
- Текст системного объявления.
- Данные для Telegram уведомлений.

# Service CRM - CRM для управления заявками

## Обзор
Современная CRM-система для управления сервисными заявками, ремонтом и обслуживанием в организациях. Профессиональный "строгий" интерфейс, гибкая настройка SLA и поддержка гибридного хранилища данных.

## Основные возможности
- **Жизненный цикл заявки:** Полный цикл от создания до завершения (Новая, Назначена, В работе, Выполнено, Отклонено).
- **Ролевая модель (RBAC):**
    - **Администратор:** Полный доступ, управление пользователями, настройка системы.
    - **Начальник отдела:** Назначение исполнителей через Drag-and-Drop, аналитика.
    - **Ответственный сотрудник:** Создание заявок, прикрепление файлов.
    - **Исполнитель:** Выполнение задач, отчетность, комментарии.
- **Интеллектуальный SLA:** Автоматический расчет дедлайнов с учетом рабочих часов (настраиваемо) и праздничных дней.
- **Строгий интерфейс:** Корпоративный дизайн в стиле Slate/Blue, поддержка Темной темы.
- **Система подсказок:** Интегрированные Tooltips для обучения персонала прямо в интерфейсе.
- **Гибридное хранилище:** Бесшовное переключение между JSON-файлами и базой данных MySQL.

## Установка
1. Загрузите файлы на PHP-хостинг (PHP 7.4+).
2. Убедитесь, что директория `data/` доступна для записи (`chmod -R 777 data/`).
3. Логин/пароль по умолчанию: `admin` / `admin`.

## Технологический стек
- **Frontend:** Vue.js 3, Tailwind CSS (Strict Theme), Animate.css.
- **Backend:** PHP (Чистая API архитектура), JWT Auth.
- **База данных:** JSON или MySQL (с автогенерацией таблиц).

Premium Forest Parallax adds a premium immersive interactive nature parallax effect to the edges of your website.

== Description ==

Premium Forest Parallax brings the calming, living presence of nature to any WordPress website. By placing detailed, high-performance parallax-layered leaves along the screen edges, the center remains fully readable and interactive. Powered by WebGL2, Three.js, and Custom GLSL Shaders, it falls back gracefully to HTML5 Canvas2D for older devices, offering an incredible 60 FPS performance.

== Installation ==

1. Upload `premium-forest-parallax.zip` to your WordPress site.
2. Activate the plugin through the 'Plugins' menu.
3. Configure your settings in the 'Forest Parallax' admin page.

== Frequently Asked Questions ==

= Does it affect performance? =
No, it includes automatic profiling (Ultra, High, Medium, Low, Lite) that dynamically adjusts particle count, disables bloom/blur, or switches to a lightweight Canvas2D renderer on low-end systems.

= Is it mobile-friendly? =
Absolutely. It auto-reduces element count and turns off post-processing on mobile devices.

# VSPRINT - Промышленная маркировка

Профессиональная система для дизайна и печати промышленных этикеток.

## Особенности
- **Визуальный редактор**: Drag-and-drop конструктор на базе Konva.js.
- **Поддержка стандартов**: EAN-13, Code128, QR-код, DataMatrix.
- **ГОСТ 14192-96**: Библиотека манипуляционных знаков (Хрупкое, Беречь от влаги и др.).
- **Каталог товаров**: Управление номенклатурой с автоматической подстановкой данных в шаблоны.
- **Переменные**: Поддержка тегов `{PRODUCT}`, `{DATE}`, `{BATCH}`, `{ALCOHOL}`, `{VOLUME}` и др.
- **Печать**: Генерация высококачественных PDF-файлов (300 DPI) через TCPDF.
- **Безопасность**: Авторизация по токену, защищенные API маршруты.
- **Хранилище**: Локальное JSON-хранилище (без необходимости SQL).

## Установка

1. Требования: PHP 8.1+, Node.js 18+.
2. Установите зависимости backend:
   ```bash
   composer install
   ```
3. Установите зависимости frontend и соберите проект:
   ```bash
   cd frontend
   npm install
   npm run build
   ```
4. Запустите сервер:
   ```bash
   php -S localhost:8080 index.php
   ```

## Использование
- Логин/пароль по умолчанию: `admin` / `admin`.
- Создайте шаблон в Редакторе.
- Добавьте товары в Каталог.
- Используйте модуль Печать для объединения шаблона с данными товара и получения PDF.

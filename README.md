# LabelPro - Профессиональная система печати промышленных этикеток

Профессиональное desktop/web приложение для печати промышленных этикеток на коробки, кеги, паллеты, бутылки и транспортную тару.

## Особенности
- **Профессиональный интерфейс**: Современная темная тема, оптимизированная для промышленного использования.
- **Визуальный редактор (Drag & Drop)**: Полноценный конструктор на базе React и Konva с поддержкой слоев и сетки.
- **Поддержка стандартов**: ГОСТ 14192-96 (библиотека знаков), EAN-13, Code128, DataMatrix, QR-код.
- **База данных продукции**: Каталог товаров с характеристиками для автоматической подстановки.
- **Переменные поля**: Динамические данные (дата, партия, срок годности) при печати через шаблоны `{PRODUCT}`, `{DATE}` и др.
- **Печать**: Генерация PDF с точностью до мм для термопринтеров (Zebra, TSC, XPrinter, Godex).

## Технологический стек
- **Backend**: FastAPI (Python), SQLModel, ReportLab.
- **Frontend**: React, TypeScript, Tailwind CSS, Lucide Icons.
- **Desktop**: Electron.
- **PHP Integration**: Специальные загрузчики для работы на стандартных PHP-хостингах.

## Быстрый старт (PHP сервер)
1. Разместите содержимое репозитория в корне веб-сервера.
2. Убедитесь, что Python backend запущен на порту 8000.
3. Откройте адрес сервера в браузере. Приложение загрузится через `index.php`.

## Разработка
1. **Backend**:
   ```bash
   cd backend
   pip install -r requirements.txt
   uvicorn app.main:app --reload
   ```
2. **Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

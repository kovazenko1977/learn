# Веб-приложение «ХОП» (Хозяйственно‑Оперативные Поручения)

Система управления хозяйственными и техническими заявками для медицинских учреждений и крупных организаций.

## 🚀 Особенности
- **Архитектура без БД**: Данные хранятся в JSON-файлах с использованием `flock` для обеспечения целостности.
- **Mobile-first**: Дизайн в стиле Windows 11 (Mica), оптимизированный для работы на смартфонах.
- **Многоролевая модель**: Инициатор, Исполнитель, Ответственный службы, Контролер, Руководитель, Администратор.
- **Полный цикл заявки**: От создания (с фотофиксацией) до проверки контролером и закрытия.
- **Аналитика**: Отчеты по нагрузке служб и персональной эффективности сотрудников (KPI).
- **Справочники**: Управление пользователями, службами, шаблонами и объектами (корпуса/этажи).
- **Уведомления**: Внутренняя система уведомлений и интеграция с Telegram-ботом.

## 📁 Структура проекта
- `/core/` — Ядро системы (Manager-классы, автозагрузка).
- `/data/` — JSON-хранилища данных.
- `/admin/` — Панель управления и справочники.
- `/ajax/` — API-обработчики для фронтенда.
- `/uploads/` — Фотографии заявок.
- `/assets/` — Стили, скрипты и иконки (Lucide).
- `index.php` — Дашборд пользователя.
- `create.php` — Создание новой заявки.
- `view.php` — Просмотр и управление заявкой.

## 🛠 Установка и запуск
1. Склонируйте репозиторий на сервер с PHP 8.1+.
2. Убедитесь, что папки `/data/` и `/uploads/` доступны для записи (chmod 775).
3. Запустите встроенный сервер (для разработки):
   ```bash
   php -S localhost:8000
   ```
4. Логин по умолчанию: **admin** (код доступа: **123456**).

## 🔒 Безопасность
- Вход по уникальному 6-значному коду доступа.
- Разграничение прав доступа на уровне классов ядра.
- Защита данных через `.htaccess` (в папке /data/).
- Валидация всех входящих данных и защита от CSRF.

## 📈 Аналитика
Система автоматически отслеживает:
- Среднее время выполнения заявок.
- Процент просроченных задач (SLA).
- Персональную эффективность (KPI) каждого исполнителя.

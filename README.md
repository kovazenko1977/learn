# Popup Manager

Веб-приложение для создания и управления всплывающими окнами (попапами) на сайте.

## Установка и настройка

### Требования
- PHP 7.4 или выше
- Расширение PHP `fileinfo` (для валидации изображений)
- Веб-сервер (Apache, Nginx)

### Развертывание
1. Загрузите файлы на хостинг в корневую директорию сайта.
2. Убедитесь, что папки `data/` и `uploads/` доступны для записи.
3. В Apache убедитесь, что включен `mod_rewrite`. Файлы `.htaccess` уже включены для защиты данных.

### Использование
1. Перейдите в админ-панель (корень вашего сайта) по адресу `ваш-сайт.com/index.php`.
2. Логин: `admin`, Пароль: `123456`.
3. Создайте новый попап, задайте ему "Код вызова" (например, `sale_2024`).
4. На любой кнопке вашего сайта добавьте атрибут `data-popup-code="sale_2024"`.
5. Подключите скрипт и стили на страницу (пути относительно корня):
```html
<link rel="stylesheet" href="css/popup.css">
<script src="js/popup.js"></script>
```

## Безопасность
- Папки `data/` и `src/` защищены от прямого доступа через `.htaccess`.
- Изображения проходят валидацию по MIME-типу.
- Текст попапов выводится с защитой от XSS.
- Админ-панель защищена авторизацией.

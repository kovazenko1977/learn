# Service CRM PRO — Система управления хозяйственным обеспечением предприятия (ХОП)

Полноценная CRM-система для автоматизации процессов обслуживания организаций: ремонт сантехники, электрики, оборудования и выполнение других хозяйственных работ.

## Основные возможности

*   **Многоролевая модель:** Администратор, Начальник отдела, Исполнитель, Ответственный сотрудник.
*   **Умная маршрутизация:** Автоматическое распределение заявок по отделам (Сантехника, Электрика, ИТ, Мебель и т.д.).
*   **Конструктор форм:** Создание динамических полей ввода для каждого типа заявок (текст, выбор, даты, чекбоксы).
*   **Kanban-доска:** Визуальное управление статусами заявок (Новая, В работе, Выполнено, Отклонено).
*   **Аналитика и SLA:** Отслеживание времени выполнения, просроченных задач и нагрузки на сотрудников.
*   **Безопасность:** JWT-авторизация, разделение прав доступа (RBAC), защита от XSS и CSRF.
*   **Дизайн:** Современный интерфейс "Glassmorphism" с поддержкой темной темы.

## Быстрый старт

1.  Разверните проект на PHP-сервере (PHP 8.0+).
2.  Перейдите по адресу `admin.php` для входа в панель управления.
3.  **Логин по умолчанию:** `1`
4.  **Пароль по умолчанию:** `1`
5.  Используйте кнопку "Сгенерировать демо-данные" в разделе "Опции" для наполнения системы.

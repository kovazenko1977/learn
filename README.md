# Sanatorium 2.0 — Система управления санаторием

Профессиональное веб-приложение уровня ERP/PMS для автоматизации работы санаторно-курортных комплексов.

## Особенности
- **Модульная архитектура**: Легко добавлять новый функционал.
- **Без БД**: Работает на JSON (с поддержкой SQLite), не требует установки сервера баз данных.
- **Безопасность**: Встроенная система ролей (RBAC) и защита от CSRF.
- **Современный интерфейс**: Адаптивный дизайн на Tailwind CSS.

## Быстрый старт
1. Убедитесь, что у вас установлен PHP 8.3 или выше.
2. Установите зависимости (если требуется): `composer install`.
3. Запустите встроенный сервер:
   ```bash
   php -S localhost:8000 index.php
   ```
4. Откройте в браузере: `http://localhost:8000`

## Устранение ошибки 500
Если при запуске вы видите ошибку 500, выполните команду:
```bash
composer dump-autoload
```
Это перегенерирует пути для автозагрузки классов. Также убедитесь, что папка `storage/` доступна для записи.

# LabelPro Professional Web Edition

Профессиональная промышленная система печати этикеток, оптимизированная для работы на веб-хостингах.

## Особенности
- **PHP 8+**: Работает на любом стандартном PHP-хостинге без сложных зависимостей.
- **Konva.js Editor**: Мощный визуальный редактор с поддержкой Drag-and-Drop, изменения размеров и поворота.
- **ГОСТ 14192-96**: Встроенные знаки транспортной маркировки.
- **Переменные**: Поддержка `{PRODUCT}`, `{DATE}`, `{BATCH}`.
- **База данных**: Легкая система на JSON-файлах в папке `data/`.

## Установка
1. Загрузите файлы в корневую папку сайта или подпапку.
2. Убедитесь, что папка `data/` доступна для записи (CHMOD 755 или 777).
3. Откройте `index.php` в браузере.

## Безопасность
По умолчанию аутентификация отключена для демонстрации. Чтобы включить:
1. Отредактируйте `api.php`.
2. Измените `$admin_pass`.
3. Раскомментируйте блок проверки сессии.

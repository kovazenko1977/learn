# HIS Booking System - Модуль онлайн-бронирования для санаториев

## Описание
Система онлайн-бронирования для санаториев и оздоровительных учреждений. Позволяет гостям бронировать лечебные программы, выбирать номера и оплачивать услуги.

## Технологический стек
- Backend: PHP 8.x (Pure PHP)
- Frontend: Vanilla JavaScript, CSS3 (SPA Architecture)
- Хранение данных: JSON файлы (thread-safe с использованием flock)
- Дизайн: Premium Light / Windows 11 Fluent Design

## Структура проекта
- `/assets` - CSS, JS, изображения
- `/includes` - Ядро системы, менеджеры данных
- `/data` - Хранилище JSON (защищено .htaccess)
- `/api` - API эндпоинты
- `/admin` - Панель администратора
- `index.php` - Основной интерфейс бронирования

# Универсальный Генератор Документов, Карточек и Штрих-кодов из Excel

Этот репозиторий содержит профессиональный, высокопроизводительный макрос на VBA (`UniversalGenerator.bas`), который позволяет автоматически генерировать документы, ценники, карточки товаров или отчеты на основе таблицы данных и настраиваемого графического шаблона прямо внутри Microsoft Excel. Также макрос включает полноценный векторный генератор штрих-кодов Code-39 с сохранением результатов в виде файлов изображений PNG.

## 🌟 Основные возможности

1. **Четыре режима работы**:
   - **Сетка карточек на одном листе (для печати А4)**: Идеально подходит для создания ценников, этикеток или бейджей. Автоматически рассчитывает отступы, сетку и параметры страницы А4.
   - **Создание индивидуальных листов**: Копирует шаблон на новые вкладки книги для каждой строки данных, автоматически именуя их по уникальному полю (например, ID или Наименование).
   - **Экспорт в PDF файлы**: Создает индивидуальные PDF-документы по шаблону и сохраняет их в выбранную пользователем папку.
   - **Генерация штрих-кода и экспорт в PNG изображение**: Отрисовывает векторный штрих-код стандарта Code-39 из любых буквенно-цифровых данных и экспортирует его в виде качественного графического файла `.png` без необходимости установки сторонних шрифтов!
2. **Гибкая шаблонизация через плейсхолдеры**:
   - Вы можете использовать любые заголовки столбцов из таблицы данных как плейсхолдеры в шаблоне (например, `{{Наименование}}`, `{{ID}}`, `{{Цена}}`).
   - Поддерживает любое форматирование ячеек шаблона (шрифты, цвета, границы, объединение ячеек).
3. **Автоматическая инициализация (Демо-режим)**:
   - Если макрос запускается в пустой книге Excel, он предлагает автоматически создать демонстрационный пример с готовой таблицей данных и красивым шаблоном карточки товара.
4. **Оптимизация производительности**:
   - Автоматически отключает обновление экрана, пересчет формул и события на время генерации, что ускоряет обработку тысяч строк в несколько раз.

## 🛠️ Инструкция по установке и запуску (Шаг за шагом)

### Шаг 1: Скачайте файл макроса
Скачайте или скопируйте файл `UniversalGenerator.bas` на свой компьютер.

### Шаг 2: Откройте Microsoft Excel
1. Создайте новую книгу Excel или откройте существующий рабочий файл.
2. Убедитесь, что книга сохранена в формате с поддержкой макросов (`.xlsm`).

### Шаг 3: Импортируйте макрос в редактор VBA
1. Нажмите комбинацию клавиш **Alt + F11**, чтобы открыть редактор Visual Basic for Applications.
2. В верхнем меню выберите **File** -> **Import File...** (или нажмите **Ctrl + M**).
3. Выберите файл `UniversalGenerator.bas` и нажмите **Open**.
4. В левой панели проекта появится модуль `UniversalGenerator`.
5. Закройте редактор VBA (или нажмите **Alt + Q**).

### Шаг 4: Запустите макрос
1. Вернитесь в Excel и нажмите клавиши **Alt + F8** (окно списка макросов).
2. Выберите макрос `RunGenerator` и нажмите **Выполнить** (Run).
3. Выберите нужный режим от **1** до **4** в диалоговом окне:
   - Выберите **4**, чтобы сгенерировать штрих-код из введенной строки и сохранить его в файл изображения.

## 📦 Генерация и сохранение штрих-кода в изображение

Режим **4** макроса предлагает:
1. Окно ввода данных: Поддерживаются заглавные латинские буквы, цифры и символы `- . $ / + %` и пробел.
2. Окно выбора папки и имени файла: Автоматически предлагает имя `Штрихкод_ВашиДанные.png`.
3. Макрос рисует векторный штрих-код на временном листе, добавляет подпись и подгоняет размеры, после чего с помощью специального метода `Chart.Export` конвертирует вектор в файл изображения PNG высокой четкости.

## 📋 Требования к структуре листов для пакетного генератора

### 1. Лист «Данные»
- Первая строка должна содержать уникальные заголовки столбцов (без специальных символов, рекомендуется использовать буквы и символ подчеркивания).
- Все последующие строки — это записи, на основе которых будут генерироваться карточки/документы.

### 2. Лист «Шаблон»
- Содержит визуальное оформление будущей карточки или документа.
- Плейсхолдеры оформляются в двойных фигурных скобках: `{{Имя_Колонки}}`. Регистр букв и пробелы должны точно совпадать с заголовками на листе «Данные».

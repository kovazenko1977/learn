# LabelPro Elite

Профессиональная система для дизайна и печати промышленных этикеток.

## Возможности
- **Визуальный редактор**: Drag-and-drop конструктор на базе Konva.js.
- **Поддержка ГОСТ 14192-96**: Библиотека из 12 транспортных знаков.
- **Штрихкоды**: EAN-13, Code128, QR-код, DataMatrix.
- **Динамические поля**: Автоподстановка данных из каталога ({PRODUCT}, {BATCH}, {DATE} и др.).
- **Каталог товаров**: Управление базой продукции, состав, производители, сроки годности.
- **Импорт**: Массовая загрузка товаров из Excel (XLSX) и CSV.
- **Печать**: Генерация PDF высокого качества для термопринтеров (58мм, 100мм) и A4.
- **Интерфейс**: Темная и светлая темы, стиль Zebra Designer / BarTender.

## Установка и запуск

### Требования
- PHP 8.1 или выше
- Расширения PHP: `gd`, `bcmath`, `xml`, `mbstring`, `pdo_sqlite`, `zip`, `fileinfo`
- Composer

### Быстрый старт
1. Склонируйте репозиторий.
2. Установите зависимости:
   ```bash
   composer install
   ```
3. Запустите встроенный сервер PHP из корня проекта:
   ```bash
   php -S localhost:8080 index.php
   ```
4. Откройте в браузере: `http://localhost:8080`

## Структура проекта
- `src/App/` — Бэкенд (Контроллеры, Модели, Сервисы)
- `public/` — Собранный фронтенд и точка входа API
- `frontend/` — Исходный код React + TypeScript
- `data/` — База данных SQLite
- `public/assets/signs/` — Библиотека знаков ГОСТ в формате SVG

Разработано специально для промышленной маркировки кег, коробок, паллет и пищевой продукции.

# NewsManager

Профессиональное веб-приложение для управления новостями и контентом с поддержкой шорткодов.

## Особенности
- **Безопасность:** Доступ по 6-значному PIN-коду.
- **Интерфейс:** Современный дизайн в стиле Mica/Glassmorphism.
- **Контент:** Полноценный визуальный редактор (Quill.js) с поддержкой вставки изображений и HTML.
- **Шорткоды:** Каждому разделу присваивается уникальный шорткод для вставки на сайт.
- **Планирование:** Возможность установки даты публикации и снятия с публикации.
- **Резервное копирование:** Создание ZIP-архивов всех данных одной кнопкой.

## Установка
1. Разместите файлы на сервере с поддержкой PHP 7.4+.
2. Убедитесь, что директория `data/` доступна для записи.
3. По умолчанию PIN-код: `123456`.

## Использование шорткодов
Для отображения новостей раздела на вашем сайте используйте следующий код:
```html
<div id="news-container"></div>
<script>
fetch('/api/shortcode.php?id=ID_РАЗДЕЛА')
  .then(response => response.text())
  .then(html => document.getElementById('news-container').innerHTML = html);
</script>
```

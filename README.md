# LabelPro - Профессиональная система печати промышленных этикеток

Профессиональное desktop/web приложение для печати промышленных этикеток на коробки, кеги, паллеты, бутылки и транспортную тару.

## Особенности
- **Визуальный редактор (Drag & Drop)**: Конструктор этикеток на базе React и Konva.
- **Поддержка стандартов**: ГОСТ 14192-96, EAN-13, Code128, DataMatrix, QR-код.
- **База данных продукции**: Каталог товаров с характеристиками для автоматической подстановки.
- **Переменные поля**: Динамические данные (дата, партия, срок годности) при печати.
- **Массовая печать**: Импорт данных из Excel/CSV.
- **Термопечать**: Поддержка принтеров Zebra, TSC, XPrinter, Godex.

## Технологический стек
- **Backend**: FastAPI (Python), SQLAlchemy, ReportLab.
- **Frontend**: React, TypeScript, Tailwind CSS, Konva.
- **Desktop**: Electron.
- **Database**: SQLite (по умолчанию) / PostgreSQL.
- **Containerization**: Docker.

## Структура проекта
- `backend/`: API сервер и логика генерации.
- `frontend/`: Веб-интерфейс редактора и управления.
- `electron/`: Конфигурация десктопной версии.
- `assets/signs/`: Библиотека знаков ГОСТ 14192-96.

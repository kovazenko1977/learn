# 🏥 PWA-приложение «МедСервис»

**«МедСервис»** — современное корпоративное PWA-приложение для больниц и медицинских центров. Предназначено для автоматизации работы обслуживающего персонала, оперативного приема и исполнения заявок, внутренней коммуникации сотрудников, быстрого вызова служб и экстренного реагирования.

Приложение сочетает мобильный интерфейс (PWA) для смартфонов и планшетов с полнофункциональной десктопной PC-версией.

---

## 🚀 ОСНОВНЫЕ ВОЗМОЖНОСТИ

- 📱 **Полноценное PWA (Progressive Web App):**
  - Установка на Android (APK-style standalone) и iOS (iPhone/iPad: «Добавить на экран Домой»).
  - Кэширование интерфейса через Service Worker для работы в офлайн-режиме.
  - Поддержка Web Push-уведомлений.
  - Оптимизированный адаптивный дизайн (светлая и темная темы).
- 📋 **Управление заявками:**
  - Создание заявок за 30 секунд с категорией, корпусом, этажом, кабинетом и фотографиями.
  - Автоматическое определение ответственной службы по категории.
  - Расчет SLA (сроков реакции и выполнения).
  - Управление статусами: *Новая 🔵*, *Принято 🟡*, *В исполнении 🟠*, *Выполнено 🟢*.
- 🚨 **Экстренная кнопка «АВАРИЯ»:**
  - Мгновенная отправка аварийного сигнала диспетчерской службе и руководителям.
- ☎ **Телефонный справочник служб:**
  - Звонки в 1 клик по кнопке `tel:` (основной, аварийный и внутренний номер).
  - Поиск по службе, фамилии, должности или номеру телефона.
- 💬 **Чаты и коммуникация:**
  - Общий чат сотрудников.
  - Личные сообщения (DM).
  - Комментарии и обсуждение внутри каждой заявки.
- 📊 **Аналитика и экспорт:**
  - Статистика по заявкам, службам и просрочкам SLA.
  - Экспорт списков заявок в CSV.
  - Создание и восстановление полных резервных копий JSON-базы.

## 🛠 ТЕХНИЧЕСКИЙ СТАК

- **Backend:** PHP 8+ (без серверного Node.js, Docker или тяжелых фреймворков).
- **Data Storage:** Файловое хранилище JSON (`data/*.json`) с асинхронной блокировкой файлов (`flock`).
- **Storage Abstraction:** Архитектурный слой `StorageInterface` (`JSONStorage` / `MySQLStorage`) для легкого перехода на MySQL в будущем.
- **Frontend:** Vanilla JS ES6+, HTML5, CSS3 Variables, SPA-навигация без перезагрузок.
- **PWA:** `manifest.json`, Service Worker (`sw.js`), Web Push API.

## 📥 ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ЗАПУСКУ

### 1. Требования к серверу
- Веб-сервер: Apache, Nginx или LiteSpeed.
- PHP версии **8.0 или выше**.
- Расширения PHP: `json`, `mbstring`, `fileinfo`, `gd` (для обработки изображений и генерации иконок).
- Поддержка HTTPS (для работы PWA и Service Worker).

### 2. Загрузка файлов
1. Скачайте дистрибутив и разпакуйте все файлы в корневую директорию вашего PHP-хостинга (или подпапку, например, `public_html/medservice`).
2. Убедитесь, что структуры каталогов сохранены:
   ```text
   ├── api/
   │   └── index.php
   ├── assets/
   │   ├── css/style.css
   │   ├── js/app.js
   │   └── icons/
   ├── data/
   │   ├── .htaccess
   │   └── *.json
   ├── includes/
   │   ├── Auth.php
   │   ├── Storage.php
   │   └── Upload.php
   ├── uploads/
   │   └── .htaccess
   ├── index.php
   ├── manifest.json
   ├── sw.js
   └── README.md
   ```

### 3. Настройка прав доступа (CHMOD)
Установите права на запись для веб-сервера (пользователь `www-data` / `chmod 775` или `777` на хостинге):
```bash
chmod -R 775 data/
chmod -R 775 uploads/
```
> **Безопасность:** Папки `data/` и `uploads/` уже защищены специальными `.htaccess` файлами, запрещающими прямой веб-доступ к JSON и исполнение PHP-скриптов.

### 4. Первоначальный запуск (Setup Wizard)
1. Откройте адрес вашего приложения в браузере (например, `https://your-hospital.by/`).
2. При первом заходе автоматически откроется экран **«Первоначальная настройка»**.
3. Укажите:
   - Название учреждения (например: *Городская Клиническая Больница «МедСервис»*);
   - ФИО Главного администратора;
   - Номер мобильного телефона (используется как логин, например: `+375291234567`);
   - Пароль (6 цифр).
4. Нажмите **«Создать систему МедСервис»**. Система автоматически создаст учетные записи администратора и диспетчера, инициализирует службы и заблокирует повторный запуск мастера настройки.

## 📱 УСТАНОВКА НА СМАРТФОНЫ И ПЛАНШЕТЫ

### Android
1. Откройте сайт приложения в Chrome.
2. Вплывет подсказка **«Добавить МедСервис на главный экран»** (или выберите в меню Chrome пункт *«Установить приложение»*).
3. Приложение появится в списке установленных программ.

### iOS (iPhone / iPad)
1. Откройте сайт приложения в Safari.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх) в нижней панели.
3. Выберите **«На экран «Домой»»**.

## 🗄 ПЕРЕХОД С JSON НА MYSQL

При увеличении объема данных приложение готово к переключению на базу данных MySQL:
1. Создайте таблицы MySQL согласно структурам моделей в `includes/Storage.php`.
2. Измените имя класса в `StorageProvider::getInstance()`:
   ```php
   return new MySQLStorage($pdoConnection);
   ```
Весь интерфейс и REST API продолжат работать без каких-либо изменений!

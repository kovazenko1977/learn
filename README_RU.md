# Orion Config Pro — Инструкция по запуску

Современная инженерная платформа для конфигурирования систем безопасности «Орион» (Болид).

## Системные требования

- **Python**: 3.12+
- **PHP**: 8.1+ (для веб-интерфейса)
- **ОС**: Windows 10/11, Linux

## Быстрый запуск

### Windows
Запустите файл `run.bat`. Он автоматически запустит:
1. Python backend (порт 8000).
2. PHP сервер (порт 8080).

Откройте в браузере: `http://localhost:8080`

### Linux
```bash
./run.sh
```

## Ручной запуск

1. **Запуск Backend (Python)**:
   ```bash
   python main.py
   ```
2. **Запуск Frontend (PHP)**:
   ```bash
   php -S localhost:8080 -t .
   ```

## Особенности
- **PHP Entry Point**: Корневой `index.php` автоматически перенаправляет в `public/`.
- **Hybrid Architecture**: PHP обслуживает статический контент, Python обрабатывает бизнес-логику и работу с оборудованием.
- **PWA**: Приложение можно установить на мобильное устройство через браузер.

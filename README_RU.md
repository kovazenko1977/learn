# Orion Config Pro — Инструкция по запуску

Современная инженерная платформа для конфигурирования систем безопасности «Орион» (Болид).

## Системные требования

- **Python**: 3.12 или выше
- **ОС**: Windows 10/11 (рекомендуется), Linux, macOS

## Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone <url_репозитория>
   cd orion-config-pro
   ```

2. **Создайте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv venv
   # Активация для Windows:
   venv\Scripts\activate
   # Активация для Linux/macOS:
   source venv/bin/activate
   ```

3. **Установите зависимости**:
   ```bash
   pip install .
   ```

## Запуск приложения

Запустите основной файл приложения:

```bash
python main.py
```

При запуске произойдет следующее:
1. Автоматически запустится локальный backend-сервер (FastAPI) на порту 8000.
2. Инициализируется база данных SQLite (`orion_config.db`).
3. Откроется графический интерфейс пользователя (PySide6).

## Разработка и тестирование

Для запуска тестов используйте:
```bash
PYTHONPATH=. pytest
```

## Структура проекта

- `app/ui`: Графический интерфейс (View и ViewModels).
- `app/api`: Локальный API для работы с данными и оборудованием.
- `app/domain`: Бизнес-сущности и схемы данных.
- `app/infrastructure`: Работа с БД и протоколы связи (RS-232/485, TCP).
- `app/services`: Движок сценариев и системная логика.

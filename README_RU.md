# Orion Config Pro

Современная инженерная платформа для конфигурирования систем безопасности «Орион» (Болид).

## Особенности
- **Web-платформа**: Работает в браузере, оптимизирована для мобильных устройств.
- **PWA**: Поддерживает установку как мобильное приложение.
- **API**: Backend на FastAPI с использованием JSON.
- **Дизайн**: Адаптивный интерфейс на Tailwind CSS.

## Установка и запуск

1. Установите зависимости:
   ```bash
   pip install .
   ```
2. Запустите приложение:
   ```bash
   python main.py
   ```
3. Откройте в браузере: `http://localhost:8000`

КАК УСТАНОВИТЬ WESBOOKING НА КОМПЬЮТЕР (WINDOWS)

1. УСТАНОВКА PHP
   - Скачайте PHP для Windows: https://windows.php.net/download/ (версия Thread Safe, x64).
   - Распакуйте архив в папку C:\php
   - Добавьте C:\php в переменную окружения PATH (Свойства системы -> Дополнительно -> Переменные среды).
   - В папке с PHP переименуйте php.ini-development в php.ini.

2. ЗАПУСК ПРОГРАММЫ
   - Скопируйте все файлы wesbooking в удобную папку на диске.
   - Зайдите в папку windows/ и запустите run.bat.
   - Оставьте окно консоли открытым.
   - Откройте браузер и перейдите по адресу: http://localhost:8080

3. НАСТРОЙКА ОБНОВЛЕНИЙ
   - После запуска зайдите в "Настройки" -> "Синхронизация".
   - Укажите адрес вашего веб-сервера (если он есть) для обмена данными.

4. ОБНОВЛЕНИЕ ПРОГРАММЫ
   - Просто замените файлы программы на новые (кроме папки data/, где хранятся ваши данные).

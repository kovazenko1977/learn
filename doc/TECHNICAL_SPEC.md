# Техническое описание wesbooking Pro Elite

## 1. Общие сведения
wesbooking Pro Elite — это автономная система управления объектами размещения (PMS), специально оптимизированная для санаториев, домов отдыха и оздоровительных комплексов. Система заменяет разрозненные Excel-файлы единым веб-интерфейсом с поддержкой многопользовательской работы и мобильных устройств.

## 2. Архитектура системы
- **Backend:** PHP 8.1+ (Standalone, без тяжелых фреймворков для максимальной скорости).
- **База данных:** JsonStore — собственная реализация документоориентированного хранилища на базе JSON-файлов с блокировками уровня файлов (`flock`) для предотвращения коллизий при записи.
- **Frontend:** Modern HTML5/CSS3 (Mica Design), Vanilla JavaScript.
- **Namespacing:** PSR-4 (`Sanatorium\Core`).
- **Безопасность:** RBAC (Role-Based Access Control), защита данных через `.htaccess`, хеширование паролей BCrypt, аудит всех действий.

## 3. Ключевые модули
- **BookingManager:** Ядро логики бронирования. Учитывает типы размещения (суточное/почасовое), вместимость (основные/доп. места) и гендерные правила.
- **PlanningManager:** Система постановки и контроля задач для персонала.
- **AuditLogger:** Логирование всех изменений статусов и критических действий.
- **SyncManager:** Модуль двусторонней синхронизации между локальной и облачной версиями.

## 4. Структура данных
Данные хранятся в папке `data/` в формате JSON:
- `bookings.json`: Все записи о бронированиях.
- `rooms.json` / `room_classes.json`: Номерной фонд и категории.
- `guests.json`: Картотека клиентов с историей и медицинскими заметками.
- `settings.json`: Глобальные настройки и параметры внешнего вида.

ПРОЕКТ: Sanatorium Booking System (Система бронирования санатория)
ВЕРСИЯ: 8.0 (Standalone PHP Edition)
РАЗРАБОТЧИК: Коваженко С.Б. (wes.by)

КОНЦЕПЦИЯ:
Модульная автономная экосистема для управления санаторно-курортным комплексом. Система работает независимо от сторонних CMS и баз данных (используется JSON-хранилище), что обеспечивает максимальную переносимость, скорость работы и безопасность данных. Дизайн выполнен в стиле Windows 11 (Mica/Glassmorphism) для создания ощущения профессионального Enterprise-приложения.

ОСНОВНЫЕ МОДУЛИ:
1. Ядро (Core): PSR-4 совместимая архитектура, менеджеры бронирования, аналитики, пользователей и планирования.
2. Админ-панель (Desktop): Полнофункциональный интерфейс для управления номерным фондом, справочниками (процедуры, услуги, пакеты) и персоналом.
3. Мобильный интерфейс (Mobile Web): Облегченная версия для персонала "в полях" с интерактивной шахматкой и списком задач.
4. REST API (v1): Полноценный API для интеграции с внешними сервисами и мобильными приложениями (Android/iOS).
5. Система планирования: Учет ежедневных задач персонала (уборка, ремонт) с привязкой к датам и номерам.
6. Аналитика: Сбор данных о доходах, популярности услуг и загрузке номерного фонда в реальном времени.

ТЕХНИЧЕСКИЙ СТЕК:
- Язык: PHP 8.3+
- База данных: File-based JSON Store с поддержкой блокировок (flock) для предотвращения коллизий.
- Frontend: Vanilla JS, Modern CSS (CSS Variables, Grid, Flexbox), Lucide Icons.
- Безопасность: Token-based API Auth, сессионная авторизация, защита данных через .htaccess.

ИНТЕГРАЦИОННЫЕ ВОЗМОЖНОСТИ:
Проект легко встраивается в другие системы как независимый подмодуль. API позволяет использовать его в качестве бэкенда для мобильных приложений, а встроенный WebParser позволяет импортировать данные с существующих сайтов.

СТРУКТУРА:
